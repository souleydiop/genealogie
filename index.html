🗂️ Projets

Chaque projet est un arbre indépendant. Le nom du projet actif s'affiche en haut de l'écran (appuyez dessus pour changer).

⬇️ Exporter (sauvegarde)

Téléchargez les données de ce projet dans un fichier JSON. Enregistrez-le ensuite sur Google Drive depuis le menu de partage pour le mettre en sécurité.

⬆️ Importer

Restaurez les données de ce projet depuis un fichier JSON précédemment exporté. Cela remplace les données du projet actif (les autres projets ne sont pas touchés).

🖨️ Export PDF

Génère une liste imprimable de toutes les personnes, groupées par génération. S'ouvre dans la boîte de dialogue d'impression : choisissez "Enregistrer en PDF" comme destination.

🌐 GEDCOM

Format standard utilisé par les logiciels de généalogie (Gramps, FamilySearch, Geneanet, Ancestry…). Pratique pour échanger vos données avec ces outils.

🗑️ Réinitialiser

Supprime définitivement toutes les personnes de ce projet (les autres projets ne sont pas affectés). Pensez à exporter avant si besoin.

ℹ️ À propos

Application installée en PWA — toutes les données restent sur votre téléphone (stockage local). Utilisez l'export/import pour les sauvegarder ou les transférer.
